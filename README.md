# SVGA 缩略图工坊

纯前端 SVGA 缩略图工具。文件只在当前浏览器中解析，不会上传到服务器。

## 使用方法

1. 使用 Windows Chrome 打开 `index.html`。如浏览器限制本地文件解析，请通过任意静态文件服务器打开本目录。
2. 上传或拖入 `.svga` 文件。
3. 使用自动推荐帧，或通过时间轴、上一帧/下一帧和播放功能手动选择。
4. 调整输出尺寸、内容比例与位置。
5. 点击“导出透明 PNG”。

## 功能范围

- 静态与动态 SVGA 解析、播放和精确选帧
- 基于可见面积、主体居中、透明度和边缘裁切的自动推荐帧
- 原始、512、600、800、1024 方形输出尺寸
- 保持比例缩放、位置微调、居中和主体自动适配
- 真正带 Alpha 通道的 PNG 导出
- SVGA 1.x 通过项目内置 JSZip 提供兼容支持

## 测试素材

`tests/` 中的 SVGA 文件仅用于本地功能验证，不会被页面自动加载。
